# LinkedIn Content Strategy & Growth

A simple, single-page report for the Week 5 main project: a small LinkedIn content campaign for **AiLif Digital** and **EchoMind AI**.

## Live Demo

 https://ainnne0130-sudo.github.io/linkedIn-content-strategy/

## What This Project Shows

- Process followed (Research to Improve)
- Campaign summary (impressions, clicks, reactions, engagement)
- Target audience and content pillars for both pages
- Content calendar (6 posts)
- Performance table for every post
- Learnings: Continue / Change / Test

## Files

| File | Purpose |
|---|---|
| `index.html` | The webpage (Bootstrap 5) |
| `data.js` | All post data and metrics |
| `README.md` | Project documentation |

## How to Update Metrics

1. Open `data.js` on GitHub.
2. Click the pencil icon (Edit).
3. Change the numbers for a post (use `null` for pending data).
4. Click **Commit changes**.
5. The live page updates in 1-2 minutes.
